01

Topological sort

Kahn's algorithm, layered by BFS

Generates a valid ordering of courses respecting all prerequisites. Each BFS layer corresponds to one semester; courses in the same layer can be taken simultaneously.

def topological_sort_kahn(courses, prerequisites):
    in_degree = calculate_in_degrees(courses, prerequisites)
    queue = [c for c in courses if in_degree[c] == 0]
    result = []

    while queue:
        course = queue.pop(0)
        result.append(course)
        for dependent in get_dependents(course):
            in_degree[dependent] -= 1
            if in_degree[dependent] == 0:
                queue.append(dependent)

    if len(result) != len(courses):
        return None  # cycle detected
    return result
Time · O(V + E)
02

Cycle detection

DFS with three-color marking

Detects circular dependencies using DFS. Each node is colored white (unvisited), gray (in progress), or black (finished). A gray-to-gray edge means a cycle.

def detect_cycle_dfs(courses):
    WHITE, GRAY, BLACK = 0, 1, 2
    color = {c: WHITE for c in courses}

    def dfs(node):
        color[node] = GRAY
        for neighbor in get_dependents(node):
            if color[neighbor] == GRAY:
                return True  # cycle found
            if color[neighbor] == WHITE:
                if dfs(neighbor):
                    return True
        color[node] = BLACK
        return False

    for course in courses:
        if color[course] == WHITE:
            if dfs(course):
                return True
    return False
Time · O(V + E)
03

Reachability

Ancestor & descendant queries via BFS

Ancestor query (reverse BFS). Finds all courses that must be completed before a target, traversing prerequisite edges backward.
Descendant query (forward BFS). Finds all courses unlocked by completing a given course, traversing dependency edges forward.

Time · O(V + E) each
04

Track filtering

BFS ancestor collection on tagged nodes

When a student selects a concentration (e.g. AI/ML), the planner collects all tagged courses then BFS backward through the reverse adjacency list to gather every prerequisite ancestor. The union forms a completable subgraph for the semester planner.

Time · O(V + E)

Chapter V

How to use this planner

Pathway helps you plan your ITS Informatika degree path - 144 SKS across 8 semesters - using graph algorithms to enforce prerequisites and visualize dependencies.

01

Sidebar - Focus Track

Choose a concentration to filter the plan

Select a track from the Focus Track dropdown to filter the semester plan and graph to courses relevant to that concentration. Available tracks:

  • All Courses - shows all 109 courses with no track filter.
  • Core (Wajib) - mandatory foundation courses, semesters 1–4 plus Tugas Akhir.
  • AI & Machine Learning - machine learning, deep learning, computer vision, and related electives.
  • Cybersecurity - information security, network security, application security, digital forensics.
  • Networking & Distributed Systems - computer networks, wireless, IoT, cloud computing.
  • Software Engineering - software design, construction, quality, and project management.
  • Game Development - computer graphics, game engines, animation, and simulation.
  • Data Science - statistics, data mining, big data, time series, and applied math.
  • Database & Information Systems - database management, distributed databases, enterprise systems.

When a track is selected, all mandatory courses (semesters 1–4) are always shown alongside the track's elective courses.

02

Sidebar - Electives Toggle

Show all elective courses in the plan

When no track is selected, the plan only shows mandatory courses by default. Turn on Include all electives to display all available elective courses for semesters 5, 6, and 7 - every course offered in each semester - with no SKS cap applied to those semesters.

03

Sidebar - Completed Courses

Mark courses you have already taken

Search and check courses you have completed. Completed courses:

  • Remain visible in their semester card, marked with a ✓ and strikethrough.
  • Still count toward the semester's SKS total.
  • Are treated as prerequisites satisfied, so dependent courses appear unlocked in subsequent semesters.
  • Can be quickly removed by clicking the tag in the tags row below the list.
04

Tab I - Semester Plan

Reading and customising your plan

The plan is generated by a modified Kahn's topological sort that respects prerequisite order, semester type (odd/even), and SKS caps.

  • Semester header - shows total SKS and course count for that semester.
  • Max SKS input - change the per-semester SKS cap directly in the header of each mandatory semester (1–4). The plan re-generates immediately.
  • Course chips - each chip shows the course code, name, and SKS. When a track is active, [T] = track elective, [P] = required prerequisite.
  • Completed courses - appear at the bottom of their semester with a strikethrough.
  • Elective semesters (5–7) - show all available courses with no SKS cap. The header displays "All elective courses shown".
Graduation requirement: 144 SKS total - 126 SKS wajib (mandatory) + 18 SKS bidang keahlian (elective concentration). Must complete Tugas Akhir (5 SKS) and Kerja Praktik.
05

Tab I - Add Course

Manually add courses to a semester

Each semester card from semester 3 onwards has a + Add Course button at the bottom. Clicking it opens a picker overlay:

  • Only courses from the same odd/even parity as the target semester are shown - odd-numbered semesters only list odd-origin courses, even only even.
  • Courses already shown anywhere in the plan (or marked completed) are excluded.
  • Use the search box in the picker to filter by course code or name.
  • Each item shows the course's original semester number for reference.
  • Added courses appear with a dashed border and include a × remove button that appears on hover.
  • Their SKS is added to the semester's total immediately.
06

Tab II - Graph

Exploring the prerequisite graph

The graph visualises the entire curriculum as a Directed Acyclic Graph (DAG). Edges point from a prerequisite to its dependent course.

  • Node colour - reflects topological depth (early semesters are green/blue, later semesters shift toward orange/gold).
  • Completed nodes - shown in dark grey.
  • Hover over any node to see its name, SKS, prerequisites, and tracks.
  • Track filter - changing the sidebar track updates the graph to show only relevant nodes; prerequisite ancestors are shown in a muted colour.
  • The graph is interactive: drag nodes, scroll to zoom, click to select.
07

Tab III - Query

Inspect any course's dependencies

Select any course from the dropdown to see:

  • Ancestors - all courses you must complete before taking the selected course (reverse BFS). Total prerequisite SKS shown.
  • Descendants - all courses unlocked by completing the selected course (forward BFS). Total unlocked SKS shown.
  • Subgraph - a mini vis-network showing the selected course (gold), its ancestors (blue), and its descendants (green).
08
